### S4. 개발키트

**목적**: 개발키트를 소개하고 스마트스토어 구매 링크를 연결한다.

**구성**

```
[헤드라인]
[한 줄 정의] 개발에 필요한 모든 환경이 100% 세팅된 개발키트입니다.
[구성 3분할] 하드웨어 + 소프트웨어 + 플랫폼
[하드웨어 옵션]
[CTA]
```

**헤드라인 카피 초안**

- 비개발자도 바로 개발을 시작할 수 있도록.

**구성 3분할**

| 블록 | 카피 |
|---|---|
| ① 키트에서 바로 개발 | 파이썬(Python) 설치, Claude API 연동, 코드 편집기(VS Code / Claude Code), 웹 서버, 데이터베이스 **설치와 설정이 끝난 상태로** 제공됩니다. |
| ② 입력하면 초안, 누르면 배포 | G2ROW 플랫폼에서 요구사항을 입력하여 초안을 만들고, 버튼 하나로 배포까지 끝납니다. |
| ③ 계속 고칠 수 있습니다 | 생성한 코드가 그대로 남아 있어, **여기에 이 기능 추가해줘** 라고 요청하며 AI로 계속 다듬을 수 있습니다. |

**하드웨어 옵션**

| 카드 | 문구 |
|---|---|
| 미니 PC | 자리를 적게 차지합니다. 간단한 업무용 |
| 일반 PC | 대부분의 제조·물류 업무에 맞는 표준 사양 |
| 워크스테이션 | 데이터가 많고 연산이 무거운 환경 |
| 사내 유휴 PC | 새로 사지 않으셔도 됩니다. 회사에 남는 PC에 저희가 설치해 드립니다. |

**CTA**: 개발키트 자세히 보기(스마트스토어 외부 이동)

### S8. FAQ

**목적**: 문의 전환의 마지막 관문

**구성**: 아코디언

| # | 질문 | 답변 초안 |
|---|---|---|
| 1 | 개발을 몰라도 되나요? | 네. 엑셀로 업무를 하실 수 있다면 시작할 수 있습니다. 만들고 싶은 프로그램을 글로 작성하면 AI가 코드를 만들어 줍니다. 교육 4시간 안에 직접 하나의 프로그램을 만들어 배포까지 해봅니다. |
| 2 | 사내 데이터가 없어도 시작할 수 있나요? | 가능합니다. 처음부터 많은 데이터가 필요하지 않습니다. 먼저, 어떤 업무에 AI를 적용할지 함께 찾고 그 업무에 필요한 데이터가 무엇인지부터 차근차근 정리해 드립니다. |
| 3 | 교육으로 만든 프로그램을 실무에 써도 되나요? | 간단한 업무라면 바로 활용할 수 있습니다. 사용하면서 필요한 기능이 생기면 AI에게 요청해 계속 수정할 수 있습니다. 처음부터 완성된 프로그램을 만드는 것이 아니라, 실제로 사용하면서 필요한 만큼 발전시켜 갑니다. |

| 5 | 회사에 있는 PC로도 되나요? | 네. 최소 사양을 충족하는 기존 PC가 있다면 새로 구매하지 않아도 됩니다. 저희가 필요한 개발 환경을 설치해 드립니다. |
