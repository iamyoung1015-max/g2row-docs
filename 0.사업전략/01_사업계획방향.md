## 3. 핵심 메시지 전략

### 3.1 메시지 전환의 핵심 논점

- **기존 셀링 포인트**: 개발 환경 세팅이 어렵다 → 우리가 대신 해준다
- **허들(진입장벽) 존재**: Claude API 연동·Python 설치 + 코드 작성 및 편집 + 서버 및 인프라 구축(웹 서버 호스팅, 데이터베이스 세팅 및 구축) + 배포
- **전환**: **키트로 시작 허들을 낮추고, 교육을 통해 완성도를 높인다**

### 3.2 기존 AI 개발 시도 vs AX Dev Kit 도입

| 구분 | 기존 AI 개발 시도 | AX Dev Kit 도입 |
|---|---|---|
| **초기 세팅** | 파이썬, 에디터 개별 설치 | 클라우드 접속 즉시 완료 |
| **인프라 구축** | 서버 및 DB 별도 구매 및 연동 필요 | 키트 내 올인원 자동 구성 완료 |
| **필요 역량** | 코딩 및 서버 운영 지식 필요 | 엑셀 활용 및 업무 프로세스 이해도 |
| **소요 시간** | 수개월 단위의 외주 또는 개인 학습 | 4시간 만에 초기 모델 완성 |
| **유지 보수** | 외주 의존 또는 수정 시마다 추가 비용 발생 | 실무자가 직접 AI로 수정 및 배포 |

## 4. 상품 구성

### 4.1 전체 구조

```
AX 구축 파트너
├── ① 교육 : 제조·물류 실무자 대상 4시간 단기 과정
└── ② 키트 : 올인원 개발·배포 환경 (하드웨어 + 소프트웨어 + 플랫폼)
```

### 4.2 교육 프로그램

- **대상**: 제조·물류 기업의 **비개발자 실무자**
- **시간**: **4시간** 단기 실무 밀착형 교육 프로그램
- **철학**: 물고기를 주는 게 아니라 **잡는 법을 알려준다**
- **효과**: 실무자는 단시간 안에 직접 결과물을 만들어 배포할 수 있고, 자체적인 디지털 전환(AX) 역량을 가지게 된다

### 4.3 키트 (Kit)

- **AX 개발 키트 (AX Dev Kit)**
- **컨셉: 밀키트** — 개발 환경 세팅부터 배포까지 전 과정을 패키지화한 올인원 상품.
- **구성** — 사전 세팅된 LLM (Claude API) + 코드 에디터 (VS Code / Claude Code) + 자동 구성 데이터베이스 (DB) + 클라우드 웹 서버 인프라
- 복잡한 설치 과정 없이, 코딩 지식 없이, 현장 실무자가 직접 업무 자동화 프로그램을 만들고 배포할 수 있다

#### (1) 소프트웨어 — 사전 세팅된 개발 환경

- 비개발자가 어려워하는 Python 설치, Claude API 연동, 코드 에디터 (VS Code / Claude Code), 웹 서버, 데이터베이스 **전부 설치·설정 완료 상태로 제공**
- 사용자는 **원격 접속만 하면 즉시 개발 시작**

#### (2) 하드웨어

| 구분 | 용도 |
|---|---|
| 미니 PC | 간단한 업무용 프로그램 |
| 일반 PC | 통상적인 업무용 프로그램 |
| 워크스테이션 PC | 대용량 데이터 처리, 고성능 연산 |

- **유휴 PC 활용 가능** — 사내 남는 PC에 동일 환경 설치 가능

#### (3) 플랫폼 ─ 인프라 자동화

```
요구사항 입력 → 프로그램 초안 자동 생성 → 자동 배포(서버 인프라·배포 상태 관리 가능)
```

## 5. 차별화

### 5.1 전체 그림

```
         ① 개발키트 ─────────────────┐
    (환경·인프라 진입장벽 제거)        │
                │                  │
                ▼                  ▼
          ② 마켓 활성화   ◀──────  ③ 위탁개발 구독제
        (초안 품질·재사용)        (못 하는 고객 흡수·수익 안정)
```

**개발키트 · 마켓 활성화 · 위탁개발 구독제** 세 가지 방향을 제시한다.

| 축 | 해결하는 문제 |
|---|---|
| **① 개발키트** | 비개발자가 개발을 **시작조차 못 하는** 문제 |
| **② 마켓 활성화** | 초안을 **빠르게 시작하는 템플릿** 제공 |
| **③ 위탁개발 구독제** | 만들다가 **못 하는 고객이 이탈**하는 문제 |

### 5.2 ① 개발키트

**정의**: 개발 환경, 서버, 배포를 통째로 패키지화한 **올인원 상품** (밀키트 컨셉)

**차별화 지점**

- 소프트웨어 외에도 **하드웨어가 포함된 실물** 제공

### 5.3 ② 마켓 활성화 `확인 필요`

**정의**: 제조·물류 **업종별 프로그램 템플릿**을 공급하는 마켓

**기대 효과**: 키트 구매자·교육 수강생이 템플릿을 골라 **즉시 적용** → 초안 품질 상향

### 5.4 ③ 위탁개발 구독제 `확인 필요`

#### 방향 A — 정액제 개발 대행

건별 견적을 없애고 **정액제로 개발 요청을 처리**

```
기존: 문의 → 상담 → 견적서 → 계약 → 개발

구독: 월 정액
      ├ 매월 개발 요청 N건 처리
      └ 건별 견적 협상 없음
```

#### 방향 B — 구축 후 유지보수 구독

운영·개선·장애 대응을 구독제로 진행

```
월 구독 전환
     ├ 장애 대응
     ├ 기능 개선 요청
     └ 버전 업데이트
```

**현재 고려 중인 채널**: 랜딩페이지, 스마트스토어(개발키트 판매), 블로그, 스레드, 페이스북, 유튜브

| 채널 | 아이템 | 내용 | 진행 단계 |

| 유튜브 | **'한부장'** | 현장 사연 접수 → 상담 및 해결 과정 공개 (현장 이해 축적 + 인바운드 유입 목적) | 구상 |
