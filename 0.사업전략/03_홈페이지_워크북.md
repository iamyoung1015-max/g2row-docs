# 03. 홈페이지 워크북

> **작성 기준일**: 2026-09-04
> **연계 문서**: [01_사업계획방향.md](01_사업계획방향.md) (정체성·상품·미결정 과제) / [02_벤치마킹_리서치.md](02_벤치마킹_리서치.md) (경쟁사 랜딩 구조·가격 기준선)
> **성격**: 홈페이지를 **실제로 만들기 위한 작업 문서.** 섹션별 목적 → 구성 → 카피 초안 → 필요 자산 → 미결정 사항 순으로 기록.

## 이 문서 사용법

- 각 섹션은 **`목적 / 구성 / 카피 초안 / 필요 자산 / 미결정`** 블록으로 구성
- 상태 표기: `확정` / `잠정`(초안 있음, 검토 필요) / `미정`(결정 대기)
- 카피 안의 **`[[TBD: ...]]`** 는 **숫자·사실이 없어서 못 쓴 자리**. 이 자리를 채우는 것이 홈페이지 제작의 실제 작업.
- 01 문서 7장 결론: **"콘텐츠가 없으면 홈페이지도 없다."** → 어떤 미결정이 어떤 섹션을 막고 있는지는 **7장 매핑표**에서 확인.

## 1. 사이트 기본 설계

### 1.1 사이트의 목표 `확정`

| 순위 | 목표 | 성공 지표 |
|---|---|---|
| 1 | **상담·문의 접수** (인바운드) | 문의 폼 제출 수 |

## 2. 공통 요소

### 2.1 헤더 / 네비게이션

**목적** — 3초 안에 "여기가 뭐 하는 곳인지" 알리고, 어디서든 상담으로 갈 수 있게 한다.

**구성**

```
┌───────────────────────────────────────────────────────────────┐
│ [G2ROW] 제조·물류 AX 구축 파트너   개발키트 교육 사례 FAQ [상담신청] │
└───────────────────────────────────────────────────────────────┘
   로고        ← 태그라인 →          ← 앵커 메뉴 →         ← CTA →
```

| 요소 | 내용 | 상태 |
|---|---|---|
| 로고 | G2ROW | `확정` |
| 로고 옆 태그라인 | **제조·물류 AX 구축 파트너** | `확정` |
| 메뉴 (Phase 1) | 개발키트 · 교육 · 구축 사례 · FAQ | `잠정` |
| 메뉴 (Phase 2 추가) | 요금 · 블로그 | `미정` |
| 우측 CTA | **상담 신청** (강조색 버튼) | `확정` |
| 동작 | 스크롤 고정(sticky) · 앵커 부드러운 이동 · 모바일 햄버거 | `확정` |

**원칙**

- **메뉴는 4개를 넘기지 않는다.** 넘어가면 "교육 사이트인지 구축 사이트인지" 다시 흐려진다 (01 문서 1.2)
- 로고 옆 태그라인은 **전 페이지 고정 노출** — 정체성 반복 노출이 목적
- 상담 CTA는 헤더에 **항상** 있어야 함 (사이트 목표 1순위)

**필요 자산**

- [ ] 로고 (SVG / PNG, 라이트·다크)
- [ ] 파비콘
- [ ] 모바일 축약 로고

### 2.2 푸터

**목적** — 신뢰(사업자 정보) + 채널 연결 + 법적 요건 충족.

**구성 4단**

```
┌─ 1단: 브랜드 ──────────┬─ 2단: 사이트맵 ─┬─ 3단: 채널 ────┬─ 4단: 문의 ──┐
│ G2ROW                  │ 개발키트        │ 블로그         │ 대표전화     │
│ 제조·물류 AX 구축 파트너 │ 교육            │ 스레드         │ 이메일       │
│ 한 줄 소개             │ 구축 사례       │ 스마트스토어   │ [상담 신청]  │
│                        │ FAQ             │ 유튜브(준비중) │              │
└────────────────────────┴─────────────────┴────────────────┴──────────────┘
┌─ 하단 바 ────────────────────────────────────────────────────────────────┐
│ 상호 · 대표자 · 사업자등록번호 · 통신판매업신고번호 · 주소                 │
│ 개인정보처리방침 | 이용약관                          © 2026 G2ROW        │
└──────────────────────────────────────────────────────────────────────────┘
```

**필수 기재 사항** `미정 — 값 확인 필요`

- [ ] 상호 / 대표자명
- [ ] 사업자등록번호
- [ ] **통신판매업 신고번호** — 키트를 스마트스토어로 판매하므로 필요
- [ ] 사업장 주소 / 대표전화 / 이메일
- [ ] **개인정보처리방침** — 문의 폼에서 개인정보를 수집하므로 **법적 필수**
- [ ] 이용약관 (교육 신청·환불 규정 포함 여부 검토)

> ⚠️ 문의 폼을 여는 순간, 개인정보 수집·이용 동의 체크박스와 처리방침 페이지가 **함께** 있어야 한다. **Phase 1 누락 금지.**

### 2.3 CTA 정책 `확정`

| 위치 | 버튼 문구 | 이동 |
|---|---|---|
| 헤더 (상시) | 상담 신청 | 문의 폼 |
| S1 히어로 · 1차 | **4시간 만에 만들어지는 과정 보기** | S5 데모 영상 |
| S1 히어로 · 2차 | 무료 상담 신청 | 문의 폼 |
| S4 개발키트 | 키트 구성 자세히 보기 | 키트 상세 → 스마트스토어 |
| S6 교육 | **1회차 신청 / 사전 설문** | 설문 폼 |
| S11 최종 | 회사 상황부터 들려주세요 | 문의 폼 |

**원칙**

- 히어로 1차 CTA는 **"상담"이 아니라 "보기"** — 신뢰가 없는 상태에서 연락처를 요구하지 않는다
- 문의 폼 입력 항목은 **5개 이내** (회사명 / 담당자 / 연락처 / 업종 / 하고 싶은 일)
- 모바일에서 전화번호는 `tel:` 링크로 바로 연결

### 2.4 톤앤매너 · 카피 원칙 `확정`

**해야 할 것**

1. **결과부터 말한다** — 허들 설명이 아니라 "엑셀 → 4시간 → 프로그램" (01 문서 3.1)
2. **숫자를 쓴다** — "빠르게" 대신 "4시간", "많이" 대신 실제 건수
3. **현장 언어를 쓴다** — 재고관리, 입출고, 생산일보, 배차
4. **한계를 먼저 말한다** — "모든 걸 다 하지는 않습니다" (01 문서 1.5). 과장하지 않는 것이 제조 고객에게는 신뢰다

**하지 말 것**

- ❌ **개발 용어를 셀링 포인트로 쓰기** — "개발 환경 세팅", "인프라 구축", "배포 파이프라인"
  → 비개발자는 *그게 어렵다는 사실 자체를 모른다.* 셀링 포인트로 작동하지 않음 (01 문서 3.1)
  → 이 단어들은 **S5 데모의 "원래는 이런 게 필요했습니다" 맥락에서만** 사용
- ❌ AX·DX·AI 전환 같은 추상어로 시작하기
- ❌ "혁신", "최고의", "완벽한"
- ❌ 근거 없는 수치

**사이트 전체에서 반복할 한 문장**

> **"엑셀 쓸 줄 아시면, 프로그램 만들 수 있습니다."**

### S1. 히어로 `잠정`

**목적** — 3초 안에 "나도 할 수 있겠다"는 반응을 만든다. 정체성과 후킹 메시지를 동시에.

**구성**

```
┌──────────────────────────────────────────────────────┐
│  [아이브로우] 제조·물류 특화 AX 구축 파트너            │
│                                                       │
│  [H1] 엑셀 쓸 줄 아시면,                              │
│       프로그램 만들 수 있습니다.                       │
│                                                       │
│  [서브] 쓰시던 재고관리 엑셀이 4시간이면              │
│         현장에서 돌아가는 프로그램이 됩니다.           │
│                                                       │
│  [CTA1 만들어지는 과정 보기]  [CTA2 무료 상담]        │
│                                                       │
│  [배지] 제조·물류 전문 · 사내 설치 가능 · 데이터 외부반출 없음│
├──────────────────────────────────────────────────────┤
│  [비주얼] 엑셀 시트 → 프로그램 화면 전환 (루프 영상)   │
└──────────────────────────────────────────────────────┘
```

**카피 초안 — H1 3안**

| 안 | 카피 | 성격 |
|---|---|---|
| **A (권장)** | **엑셀 쓸 줄 아시면, 프로그램 만들 수 있습니다** | 01 문서 3.2 채택 메시지 그대로. 검증된 후킹 |
| B | 재고관리 엑셀, **4시간 뒤엔 프로그램**입니다 | 숫자·결과 강조. 구체적이나 재고관리로 범위가 좁아 보임 |
| C | 제조·물류 현장의 일을, **직접 프로그램으로** | 정체성 강조. 후킹은 약함 |

**서브 카피 초안**

> 쓰시던 재고관리 엑셀 파일 하나면 됩니다.
> 개발 환경도, 서버도 준비하실 필요 없습니다. **키트에 접속해서 입력하면 끝입니다.**

**신뢰 배지 3개**

- `[[TBD: 제조·물류 구축 O년]]`
- `[[TBD: 구축 사례 O건]]`
- 사내 PC 설치 가능 — 데이터가 외부로 나가지 않습니다 ← **지금도 쓸 수 있는 유일한 배지**

**필요 자산**

- [ ] **엑셀 → 프로그램 전환 루프 영상** (10~15초, 무음, 자동재생) ← 보유 20분 영상에서 추출 (01 문서 6.5)

**미결정**

- [ ] H1 A/B/C 택일

### S2. 문제 공감 `잠정`

**목적** — "우리 얘기네"를 만든다. 솔루션보다 문제를 먼저 정확히 말하는 쪽이 신뢰를 얻는다.

**구성** — 헤드라인 + 체크리스트형 카드 5개

**카피 초안**

> ### 이런 상황, 겪고 계실 겁니다

| # | 카피 |
|---|---|
| 1 | 재고 수량이 **엑셀 파일마다 다릅니다.** 어느 게 맞는지 아무도 모릅니다 |
| 2 | 담당자만 아는 엑셀 서식이 있고, **그 사람이 없으면 업무가 멈춥니다** |
| 3 | 외주로 만들자니 **견적이 수천만 원**, 게다가 몇 달입니다 |
| 4 | 만들어 놨는데 **수정 한 번 하려면 또 외주**를 불러야 합니다 |
| 5 | AI로 뭔가 된다는데, **뭘 어디서부터 해야 할지** 모르겠습니다 |

**원칙** — 이 섹션에서는 **AI·자동화 이야기를 하지 않는다.** 현장 언어로만.

**필요 자산**

- [ ] 카드 아이콘 5종 (또는 텍스트만으로 처리)

### S3. 솔루션 분기 `확정`

**목적** — 방문자를 두 갈래로 나눠 각자 갈 곳을 준다. 오토프로그 이중 선택 구조(02 문서 A-1)와 동일한 장치.

**구성** — 좌우 2분할 카드

```
┌─────────────────────────┬─────────────────────────┐
```

**구성 3분할 카피**

| 블록 | 카피 |

### S5. 4시간 데모 `잠정`

**목적** — **믿게 만드는 섹션.** S1이 후킹이라면 여기가 증명. 01 문서 3.3 메시지 전개 순서를 그대로 화면화.

**구성** — 영상 1개 + 하단 4단계 타임라인

```
[영상] 엑셀 시트 → 프로그램 화면 전환 (2~3분 편집본)
   ▼
[타임라인]
 0h ─────── 1h ─────── 2h ─────── 4h
 엑셀 파일   초안 생성   기능 추가   배포·사용
```

**카피 초안**

> ### 엑셀 파일 하나로, 4시간 뒤에 이렇게 됩니다

> **원래는 이런 게 필요했습니다.**
> Claude를 설치하고, Python을 깔고, 서버를 세팅하고, 배포까지 해야 합니다.
> — 여기서 대부분 포기합니다.
>
> **키트는 이 과정을 건너뜁니다.**
> 접속 → 입력 → 클릭. 4시간이면 화면이 나옵니다.
>
> 그리고 이걸 **반복할수록 원하는 것에 가까워집니다.**
> 완성품을 드리는 게 아니라, **만드는 법을 알려 드립니다.**

> ⚠️ 개발 용어("환경 세팅", "배포")는 **이 섹션의 "원래는" 문단에서만** 사용. 셀링 포인트가 아니라 **대비용 장치**로만 쓴다 (2.4 카피 원칙).

**타임라인 4단계**

| 시점 | 내용 |
|---|---|
| 0h | 쓰시던 재고관리 엑셀을 그대로 올립니다 |
| ~1h | 프로그램 초안 화면이 생성됩니다 |
| ~2h | "여기에 입고일 추가해줘" — 말로 고칩니다 |
| ~4h | 배포. 현장에서 바로 씁니다 |

**필요 자산**

- [ ] **보유 20분 영상 → 2~3분 편집본** (01 문서 6.5) ⚠️ 최우선
- [ ] 단계별 스틸컷 4장
- [ ] 영상 자막 (음소거 자동재생 대비)
