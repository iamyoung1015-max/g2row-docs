## A. 오토프로그 (AutoFrog) — 최우선 벤치마킹

**URL**: https://autofrog.kr/ | [YouTube](https://www.youtube.com/@autofrogkr) | [Threads](https://www.threads.com/@autofrog.kr)

> ⚠️ **우리 사업 구상과 거의 동일한 구조.** 지역(부산·경남)까지 인접. 차별화 논거를 반드시 확보해야 함.

### A-1. 사업 모델
**이중 선택 구조** — 방문자에게 두 갈래를 제시:
- **① 자동화 맡기기(대행)**: "자동화할 일을 같이 찾아 만들어 드리고, 쓰는 법까지 알려 드립니다"
- **② 직접 배우기(교육)**: "AI에게 말로 시켜 프로그램을 만드는 법(바이브 코딩)을 코드 한 줄 몰라도 되게"

### A-2. 서비스 라인업

| 서비스 | 내용 |
|---|---|
| 자동화 대행 | 진단 → 범위·가격 확정 → 구축 → 인수인계 (4단계) |
| 바이브 코딩 교육 | **무료 20강** + **6주 유료 과정** (9/15 개강) |
| 무료 봇 (리드마그넷) | 정부지원사업 알리미, 나라장터 알리미 |
| 월 케어 구독 | 유지보수·개선·장애 대응 **월 10~30만원** |

### A-3. 가격 정책 — **전부 공개**

> 카피: **"가격을 전부 공개합니다"**

| 패키지 | 범위 | 납기 | 가격 |
|---|---|---|---|
| AF-S1 스타터 | 단일 업무 | 1~2주 | 50~100만원 |
| AF-S2 스탠다드 | 복합 업무 흐름 | 2~5주 | 200~500만원 |
| AF-F1 공장장 | 제조 통합 | 4~12주 | 500만원~ |
| AF-C0 케어 | 월 구독 유지보수 | 월 단위 | 월 10~30만원 |

**비교 프레임**: `SI 외주 개발 1억 원` vs `오토프로그 200~500만원`

### A-4. 신뢰 서사 (가장 강력한 무기)
> **"저도 직원 13명 제조회사 사장입니다. 저희 회사 일부터 자동화해 왔습니다."**

- 자사에 먼저 적용 → 그 결과를 상품화하는 구조
- 정량 증명: **매주 35시간 절감 / 외주 견적 1억 → 0원 / 2,068 커밋 / 자동화 30개**
- 과정 투명성: **"만들어지는 대로 화면 공유"**

### A-5. 랜딩 페이지 15단 구성 (그대로 참고 가능)

```
1  헤더/네비  ─ 브랜드 + 메뉴
2  히어로     ─ "작은 회사의 AI 업무 자동화" + CTA
3  문제 정의  ─ "이런 일을 대신합니다" (반복 업무 5가지)
4  솔루션 분기 ─ 맡기기 vs 배우기
5  무료 제공물 ─ 무료 봇 2종 + 무료 강의
6  공감       ─ "이런 밤, 겪어 보셨을 겁니다" (자사 사례)
7  증명       ─ 정량 실적 공개
8  데모       ─ ERP·그룹웨어·블로그 자동화 화면
9  가격표     ─ 패키지별 상세
10 비교표     ─ SI 외주 vs 오토프로그
11 프로세스   ─ 4단계
12 FAQ       ─ 8문항
13 최종 CTA   ─ "회사 이야기부터 들려주세요"
14 추가 리소스 ─ 교육·랩스·전자책·커뮤니티
15 푸터
```

### A-6. 우리와의 비교 및 시사점

| 항목 | 오토프로그 | G2ROW (우리) | 판단 |
|---|---|---|---|
| 타깃 | 작은 회사, 부산·경남 | 소규모 제조·물류, 울산 | **거의 동일. 지역도 인접** |
| 가격 | **전부 공개** | "정찰가 아님" → 비공개 방향 | ⚠️ **재검토 필요** |
| 교육 | 무료 20강 → 6주 유료 | 2~4시간 단기 + 무료 파일럿 | 퍼널 구조 참고 |
| 유지보수 | 월 10~30만원 구독 상품화 | **위탁개발 구독제**로 검토 중 | ⚠️ **가격 기준선 확보** |
| 리드마그넷 | 무료 봇 2종 | 없음 | ⚠️ **필요** |
| 신뢰 근거 | 자사 13명 제조회사 적용 | 제조 구축 히스토리 보유 | ✅ **레퍼런스로 전환 가능** |
| **차별점** | 소프트웨어 자동화 대행 | **개발키트 · 마켓 · 구독제 3축** | ✅ **여기가 우리 자리** |

### A-7. G2ROW 차별화 3축 대비

> 01 문서 4장에서 확정된 **차별화 3축**을 오토프로그와 직접 대조한 결과.

| G2ROW 차별화 축 | 오토프로그 대응물 | 격차 판단 |
|---|---|---|
| **① 개발키트** (하드웨어 포함 실물, 온프레미스) | **없음** — 소프트웨어 대행만 | ✅ **완전한 공백. 최우선 무기** |
| **② 마켓 활성화** (업종별 템플릿 공급) `잠정` | **없음** — 건별 맞춤 구축 | ✅ **공백. 단, 템플릿 축적에 시간 필요** |
| **③ 위탁개발 구독제** `잠정` | **있음** — 월 케어 10~30만원 | ⚠️ **이미 선점됨.** 차별화가 아니라 **필수 대응 항목** |

**해석**

- **①·②는 진짜 차별화**, **③은 따라가야 하는 기본기**. 랜딩에서 강조 순서를 이렇게 잡을 것.
- 다만 ③ 위탁개발 구독제의 **방향 A(월정액 개발 대행)** 는 오토프로그의 '케어(유지보수)'보다 넓은 범위 → 이 경우 차별화가 성립. **방향 A 채택 시 강조 가치 있음** (01 문서 7.4 결정 대상).
- ②는 오토프로그가 언제든 따라올 수 있는 영역 → **선점 속도**가 관건.

**보조 논거** (3축을 뒷받침하는 문맥)

1. **제조·물류 수직 특화** — "작은 회사 전체"가 아니라 업역을 좁혀 레퍼런스 밀도를 높임
2. **AX 통합 관점** — 프로그램만이 아니라 **인력 + 조직 문화 + 경영진 의지**를 함께 다루는 파트너
3. **공공·지자체 채널** — 세미나·제안서 기반 B2G 접근 (01 문서 6.3). 오토프로그는 B2C/B2B 온라인 중심

- **자동 생성**: 테이블 스키마 기반으로 DTO / Repository / Service 등 **서버 코드 자동 생성**, 설정·커맨드로 **페이지·프로그램 자동 생성**

- **운영 기능**: 다국어, 동적 테마, 권한 관리
- **스택**: React + Spring Boot + RDBMS, DevOps 친화 구조
- **타깃 산업**: 공공·행정, **제조·유통**, SaaS, 금융

**가격**: Basic 300만원(기본 CRUD·인증) / Admin Basic 600만원(대시보드·권한) / Admin Plus 1,200만원(통계·알림·확장)

### B-2. AXBOOT AI (axboot.dev)
- 포지션: **"AI Service Builder"**
- ⚠️ SPA 구조로 자동 수집 불가 → **직접 접속해 확인 필요**

### B-3. 시사점
1. **키트 플랫폼의 기술 대안** — 우리 "자동 초안 생성 플랫폼"을 자체 개발할지, AXBoot 계열을 얹을지 검토. **실배포 전까지 무료**이므로 **PoC 비용 0원**.

## C. BGrid Learn — 랜딩/교육 페이지 구성 참고

**URL**: https://bgrid.axisj.com/learn
**메모(원문)**: *"랜딩 페이지 용도로 좋네"*

### C-1. 제품
React + TypeScript 데이터 그리드 라이브러리. "React 업무 화면에서 복잡한 데이터를 빠르게 탐색하고 편집".

### C-2. 페이지 구성
```
1  네비 헤더        ─ 버전 + 메뉴(가이드/API/지원환경/오픈소스/플레이그라운드)
2  큐레이팅 학습경로 ─ FOUNDATION → WORKFLOW → PRODUCTION (3단계)
3  가이드 카탈로그  ─ 36개 주제 검색 인터페이스
4  상세 가이드 목록 ─ 5개 대분류 + 항목별 설명
5  푸터
```

**학습경로 카피 3단**
| 단계 | 카피 |
|---|---|
| FOUNDATION | "첫 그리드 완성하기" (설치 → 기본 → 데이터 연결) |
| WORKFLOW | "업무 상호작용 설계하기" (키보드 탐색 → 편집 → 에디터) |
| PRODUCTION | "운영 환경 준비하기" (성능 → 접근성 → 테마) |

**콘텐츠 구조**: 36개 가이드 / 5개 대주제 (시작하기 3, 데이터·컬럼 6, 상호작용·편집 16, 고급 5, 스타일·접근성 6)

**시각 표현**: 실행 가능한 **라이브 데모 링크**, 가이드별 **핵심 개념 태그 3~4개**, 초급→고급 **진행 경로 명시**, **검색 필터**

### C-3. 시사점 (01 문서 7.1 교육 커리큘럼 노출 방식의 답)
> **우리 2~4시간 교육 커리큘럼을 이 3단 학습경로 포맷에 그대로 얹을 수 있음.**

| BGrid | 우리 교육 적용안 |
|---|---|
| FOUNDATION "첫 그리드 완성하기" | **"첫 프로그램 만들기"** — 키트 접속 → 엑셀 입력 → 초안 생성 |
| WORKFLOW "업무 상호작용 설계하기" | **"내 업무에 맞게 다듬기"** — AI 프롬프트로 기능 추가·반복 개선 |
| PRODUCTION "운영 환경 준비하기" | **"실무에 배포하고 유지하기"** — 배포 → VS Code/Claude Code 유지보수 |

- **라이브 데모 링크 방식** → 키트가 "감이 안 온다"는 문제(01 문서 7.2)의 해법. **말이 아니라 실행 가능한 화면**으로 보여줄 것.
- **단계별 진행 경로 표시** → 교육 이수 후 A형(단순 활용)/B형(심화) 분기를 시각적으로 표현하기 좋은 포맷.

## D. ManualTalk — 프리미엄 가격 퍼널 + 부가상품 아이디어

**URL**: https://manualtalk.axisj.com/
**메모(원문)**: *"제품 매뉴얼 기반 근거 답변"*

### D-1. 서비스
> 카피: **"매뉴얼을 읽는 대신, 물어보세요"**
> **"등록된 제품 매뉴얼에서 필요한 내용을 찾아, 근거와 함께 답변합니다"**

- PDF 매뉴얼 업로드 → 구조화된 지식으로 변환
- **하이브리드 검색**: 정확 용어 매칭 + 의미 기반(벡터 임베딩) + 재랭킹, TOC 경로 가중치
- 브랜드 맞춤 채팅 위젯, 서비스별 독립 운영·권한 관리
- 동작: `고객 질문 → 제품 선택 → 매뉴얼 검색 → 근거 기반 답변`
- 신뢰 카피: **"근거 기준을 충족하지 않으면 추측하지 않습니다"**

### D-2. 가격 (프리미엄 3단)
| 플랜 | 조건 | 가격 |
|---|---|---|
| Free | 월 100회 답변, 1개 서비스 | 무료 |
| Plus | 월 10,000회 답변, 3개 서비스 | **월 9,900원** (런칭 할인) |
| Pro | 맞춤 | 협의 |

### D-3. 시사점
1. **프리미엄 퍼널** — `무료 체험 → 저가 월구독 → 맞춤 계약`. 우리 유지보수 상품(01 문서 7.5)에 그대로 적용 가능한 3단 구조.
2. **환각 방지를 신뢰 카피로 전환** — "추측하지 않습니다"는 AI 도입을 망설이는 제조·물류 고객에게 유효한 문장. **우리도 AI 결과물의 신뢰 문제를 정면으로 다루는 카피 필요.**
3. **부가상품 아이디어** — 제조·물류 고객은 **설비 매뉴얼·작업표준서(SOP)**를 대량 보유. 키트 상품군에 **"사내 매뉴얼 챗봇"** 을 얹으면 두 번째 판매 지점이 생김.
